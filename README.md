# Doodle Chess

Chess played as doodles on notebook paper. Red crayons (you) vs. blue ink (the computer, or a friend).

Open `index.html` in a browser. No build step.

- Tap a piece, then tap where it goes
- Three computer levels, or pass & play
- Full rules: castling, en passant, promotion, checkmate, stalemate and draws
- **Play** the computer (Sleepy Sloth, Sneaky Fox, Grumpy Owl, each with their own lines), pass & play, or **online with a friend** using a 4-letter code
- **Daily puzzle**: 80 engine-verified mate-in-1 and mate-in-2 puzzles, with a day streak
- **Learn**: 8 lessons, one per piece, plus captures and checkmate
- Coach mode warns about bad moves, with a take-back
- Timer (3/5/10 min) with doodle hourglasses, shuffle setup, pencil mode (draw a line to move)
- Talking pieces, flipbook replay, save a picture of the game
- Stars unlock sticker packs: cats, robots, dinos
- Synthesized sound effects and background music
- Crayon boxes, notebook / graph / chalkboard paper, wide-gamut P3 "HDR" colors with glow
